This viewer is a presentation layer. It reads the committed artifact files directly and never regenerates, rewrites, summarises over, or becomes the source of truth for any simulation data. Where an artifact is missing, malformed, or hash-inconsistent it says so and names the file. Where the artifacts record a field as unavailable, the recorded reason is shown as-is.

Auditor-only labelling. branches/*/step_ledger.jsonl deliberately places every actor's private context and every prompt side by side; no actor ever saw that view. Every block derived from another actor's slice of a step is wrapped in a red AUDITOR-ONLY band. The actor-prompt pane shows only the active actor's own prompt.
