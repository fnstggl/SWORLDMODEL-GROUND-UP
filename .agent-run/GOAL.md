# Goal

Build the working Concordia plus AgentSociety engineering foundation for an
intervention-centered best-action simulator across individual, team, and
societal-infrastructure scales.

---

This is the durable product objective. It survives compaction, session restart,
and context loss. It is the single authoritative statement of what this project
is for.

Do not rewrite this objective. The master implementation directive refines *how*
it is achieved; it does not replace *what* is being built.

Detailed architecture, phases, and acceptance gates are **not** recorded here.
See `.agent-run/ARCHITECTURE.md` and `.agent-run/TASK_GRAPH.json`, which remain
in `MASTER_DIRECTIVE_PENDING` state until the master implementation directive is
loaded.
